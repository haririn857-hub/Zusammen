### *“Together — Hand in Hand to Germany & Forever After”*
**A Private Companion App for Harikrishnan & Rinta Maria (Rintamol)**

---

## 🌹 The Name: *Zusammen* (pronounced *tsoo-ZAH-men*)
- **Origin**: German word meaning **"Together"**.
- **The Meaning for Us**:
  - We stand **Together** against religious boundaries and family storms.
  - We save every single rupee **Together** on small salaries.
  - We board that flight to Germany in 2028 **Together**.
  - We build a peaceful life in Germany and stay **Together** until death.
- **App Tagline**: *“Zwei Herzen, Ein Weg”* (Two Hearts, One Journey).
- **Monthly Cost**: **₹0.00 / $0.00** (Engineered to run 100% free on Supabase Free Tier for 2+ years).

---

## 📱 Cross-Platform Setup (Android + iPhone + Web)
- **Harikrishnan's Android**: Native APK via `flutter build apk --release` (or automated via GitHub Actions).
- **Rintamol's iPhone**:
  - **Phase 1 (Instant Day 1)**: Safari Web PWA (*Share → Add to Home Screen*) — 100% full screen, zero Mac needed, all Realtime features live.
  - **Phase 2 (Full Haptic Vibration)**: Free Native iOS `.ipa` via GitHub Actions macOS runner + Sideloadly (no paid Apple Developer fee needed).
- **Desktop/Web**: Shared private web dashboard hosted free on Vercel/GitHub Pages.
